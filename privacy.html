개인정보처리방침

시행일: 2026-11-07

AutoYoutube는 채널 운영자 본인만 쓰는 개인용 도구입니다. 다른 사람의 계정으로 로그인하지 않습니다.

접근하는 정보

  • youtube.upload: 운영자의 영상을 운영자의 채널에 올리고 공개 시각을 정합니다.
  • youtube.readonly: 운영자 채널의 정보와 올린 영상 목록을 읽습니다.
  • yt-analytics.readonly: 운영자 채널의 조회수 등 통계를 읽습니다.

보관과 공유

로그인 토큰과 읽어 온 정보는 운영자의 컴퓨터에만 저장됩니다. 외부 서버로 보내지 않고, 누구에게도 팔거나 공유하지 않으며, 광고에 쓰지 않습니다.

삭제

운영자는 언제든 Google 계정의 서드파티 앱 접근 권한에서 접근을 끊을 수 있고, 자기 컴퓨터의 토큰 파일을 지우면 저장된 정보도 사라집니다.

AutoYoutube의 Google 사용자 데이터 사용은 Limited Use 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

Privacy Policy

Effective: 2026-11-07

AutoYoutube is a personal tool used only by the channel owner. It does not sign in anyone else's account.

Data accessed

  • youtube.upload: upload the owner's videos to the owner's channel and set their publish time.
  • youtube.readonly: read the owner's channel details and list of uploaded videos.
  • yt-analytics.readonly: read the owner's channel statistics such as views.

Storage and sharing

Sign-in tokens and the data read are stored only on the owner's computer. They are not sent to any outside server, not sold or shared with anyone, and not used for advertising.

Deletion

The owner can revoke access at any time in their Google Account's third-party access settings, and deleting the token file on their computer removes the stored data.

AutoYoutube's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
